# Castle Combo 사진 자동인식 점수 계산기 v5

## v5 핵심 변경
- 모든 카드가 동일한 실제 규격 **64×90mm (종횡비 0.7111)** 인 점을 카드 외곽선 검출의 핵심 조건으로 사용합니다.
- 사진 전체에서 카드 테두리를 각각 찾고, 검출된 네 모서리를 **320×450 정규 카드 좌표**로 원근 보정합니다.
- 3×3 칸을 먼저 가정하지 않습니다. 카드 9장을 독립 검출한 뒤 중심 좌표로 배열 위치를 정합니다.
- 모든 카드가 동일 레이아웃이라는 점을 사용해 정규화된 카드에서 항상 같은 6개 영역을 비교합니다.
  1. 금화 비용
  2. 방패 기호
  3. 세로 카드명
  4. 일러스트
  5. 카드 능력/효과
  6. 점수 두루마리
- 위 6개 영역을 90장 스캔 원본에서 미리 만든 레이아웃 특징값과 비교하고, 카드명 한글 OCR 결과를 추가 가중치로 합산합니다.
- 카드가 180도 돌아간 경우도 두 방향을 비교해 자동 보정합니다.
- 동일 카드 중복 선택은 계속 차단됩니다.

## 촬영 팁
카드를 반듯하게 놓을 필요는 없습니다. 다만 카드 테두리 네 변이 다른 카드나 손가락에 대부분 가려지지 않게 하고, 가능하면 카드끼리 겹치지 않게 촬영하면 외곽선 검출률이 높아집니다.

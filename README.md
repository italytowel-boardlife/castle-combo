# Castle Combo 사진 자동인식 점수 계산기 v6

## v6 핵심 변경
- 3×3 칸을 먼저 가정하지 않습니다.
- 사진 전체에서 64×90mm(64:90) 비율에 가까운 카드 테두리 후보를 넉넉하게 검출합니다.
- 모든 후보를 320×450의 동일 카드 좌표로 원근 보정합니다.
- 고정 레이아웃의 카드명 / 금화비용 / 방패 / 일러스트 / 효과 / 점수 영역을 각각 비교합니다.
- **중요:** 사각형 후보가 실제 Castle Combo 카드인지 90장 스캔본과 먼저 대조합니다. 일러스트 ORB 특징점 매칭 후 RANSAC homography의 기하학적 일치점(inlier)이 적은 사각형은 카드 후보에서 탈락합니다.
- 최종 9장에만 한글 카드명 OCR을 적용하여 속도를 줄이고, OCR은 보조 판정으로 사용합니다.
- 카드 위치는 9장의 실제 중심 좌표를 찾은 뒤 마지막에 3×3으로 정렬합니다.
- 동일 카드 중복 선택은 차단합니다.

## 촬영 권장 조건
- 카드 9장의 테두리가 서로 겹치지 않게 합니다.
- 완전히 반듯할 필요는 없습니다.
- 카드 한 장이 사진에서 너무 작아지지 않도록 배열 위주로 촬영합니다.
- 강한 천장 조명이 카드 중앙에 직접 반사되지 않게 하면 가장 안정적입니다.

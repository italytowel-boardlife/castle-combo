# Castle Combo 사진 자동인식 점수 계산기 v1

기본판 78장 + Out of the Oubliette 확장팩 12장 = 총 90장을 지원합니다.

## 이번 버전에서 추가된 기능

- 휴대폰에서 `사진 촬영 / 선택`
- 3×3 카드 배열 자동 윤곽 검출
- ORB 특징점으로 90장 중 카드 자동 인식
- 인식 후보 상위 3개 표시
- 애매한 카드는 `확인 필요` 표시
- 후보를 눌러 인식 결과 수정
- 인식한 9장을 기존 점수 계산 배열에 한 번에 적용
- 자동 윤곽 검출 실패 시 `수동 4점 지정` 지원
- 원본 카드 스캔 이미지를 웹에 포함하지 않고 숫자 특징 데이터만 사용

## 사용 방법

1. 3×3 카드가 모두 보이도록 사진을 찍습니다.
2. `사진 촬영 / 선택`에서 이미지를 고릅니다.
3. `자동 분석`을 누릅니다.
4. 9장이 모두 검출되면 카드 인식이 시작됩니다.
5. `확인 필요` 카드가 있으면 상위 후보 중 실제 카드를 선택합니다.
6. `인식 결과를 배열에 적용`을 누릅니다.
7. 기존 계산기에서 남은 열쇠, 지갑의 금, 미사용 잠금 열쇠를 입력합니다.
8. 카드별 점수와 총점을 확인합니다.

### 자동 카드 검출이 실패하는 경우

`수동 4점 지정`을 누르고 아래 순서로 네 모서리 카드의 **중심**을 찍습니다.

1. 왼쪽 위
2. 오른쪽 위
3. 오른쪽 아래
4. 왼쪽 아래

웹페이지가 중간 카드의 위치를 계산한 뒤 9장을 인식합니다.

## 기술 방식

카드 인식에는 OpenCV.js의 ORB 특징점과 Hamming 거리 매칭을 사용합니다. OpenCV.js는 사용자의 브라우저에서 실행됩니다. `data/card-features.json`은 사용자가 제공한 90장 스캔에서 미리 추출한 ORB descriptor이며 원본 스캔 이미지는 포함하지 않습니다.

OpenCV.js 자체는 OpenCV 공식 문서의 온라인 빌드를 불러옵니다. 따라서 첫 실행 시 인터넷 연결이 필요합니다. 별도의 서버/API/API 키는 필요하지 않습니다.

## 현재 v1의 한계

- 조명 반사가 심하거나 카드가 크게 가려지면 오인식할 수 있습니다.
- 그림이나 배치가 비슷한 카드는 후보 확인이 필요할 수 있습니다.
- 현재 사진에서 금화 토큰 수와 열쇠 토큰 수까지 자동으로 세지는 않습니다.
- 뒷면 카드 자동 인식은 다음 개선 항목입니다. 현재는 인식 후 계산기에서 수동 확인이 필요합니다.

실사용에서는 자동 확정보다 `자동 인식 → 후보 확인 → 점수 계산` 흐름을 권장합니다.


## v2 한글판 카드명
- 화면에 표시되는 영문/네덜란드어 카드명을 제거했습니다.
- 카드명은 사용자가 제공한 한글판 스캔 파일명을 기준으로 90장 전체를 맞췄습니다.
- 영문명은 내부 카드 ID/이미지 인식 매칭에만 사용되며 화면에는 표시되지 않습니다.

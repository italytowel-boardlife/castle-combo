계산 기준 및 주의사항
  • 뒷면 카드는 카드 자체의 방패·배너·점수 조건을 모두 무시합니다.
  • 행/열 조건에는 해당 카드 자신도 포함됩니다.
  • ‘같은 행/열’은 해당 카드가 놓인 행 3장과 열 3장의 합집합이며, 중심 카드는 한 번만 셉니다.
  • 지갑 카드는 해당 카드에 저장된 금을 직접 입력하세요.
  • 은행가는 배열의 모든 지갑에 저장된 금 전체를 계산합니다.
  • 확장 카드의 잠금 능력을 사용하지 않았다면 해당 카드의 “잠금 열쇠 미사용”을 체크하세요. 게임 종료 시 일반 열쇠에 합산됩니다.
  • 뒷면 카드의 인쇄 비용은 행·열 비용 합계와 서로 다른 비용 계산에서 제외됩니다.

# Castle Combo 사진 자동인식 점수 계산기 v4

## v4 핵심 변경
- 3×3 셀 위치를 먼저 가정하지 않고 사진 전체에서 카드 테두리를 개별 검출합니다.
- 각 카드의 네 모서리를 이용해 원근 보정 후 360×500 정면 카드 이미지로 변환합니다.
- 카드 판별은 다음 4가지 정보를 합산합니다.
  1. 카드 전체 일러스트 ORB 특징점
  2. 좌상단 금화 비용 기호 영역 특징점
  3. 우상단 방패 기호 영역 특징점
  4. 좌측 세로 한글 카드명 OCR(Tesseract.js)
- 카드 9장을 찾은 뒤에만 중심 좌표로 3×3 위치를 정렬합니다.
- 같은 카드의 중복 선택은 계속 차단됩니다.

## 주의
- OCR은 Tesseract.js CDN과 한국어 언어 데이터를 최초 1회 내려받습니다. 비용은 없지만 인터넷 연결이 필요합니다.
- 강한 반사로 카드명 전체가 날아가도 일러스트/비용/방패 특징을 함께 사용해 판별합니다.
- 카드가 겹치거나 테두리 대부분이 가려진 경우 자동 테두리 검출은 실패할 수 있습니다.

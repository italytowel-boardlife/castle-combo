# Castle Combo 점수 계산기

GitHub Pages에서 바로 실행되는 정적 웹페이지입니다. 서버나 빌드 과정이 필요하지 않습니다.

## 배포 방법

1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 `index.html`, `style.css`, `app.js`를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` / `(root)`를 지정한 뒤 저장합니다.
5. 잠시 후 표시되는 주소로 접속합니다.

## 사용법

- 실제 게임 종료 배열과 동일하게 3×3 칸에 카드를 선택합니다.
- 뒷면으로 놓은 카드는 `뒷면`을 체크합니다.
- 지갑 카드에는 저장한 금 수량을 입력합니다.
- 남은 열쇠를 입력하면 열쇠 점수가 더해집니다.
- 입력값은 브라우저의 localStorage에 자동 저장됩니다.

## 파일 구조

- `index.html`: 화면 구조
- `style.css`: 모바일/PC 반응형 디자인
- `app.js`: 78장 카드 데이터와 점수 계산식

## 점검 권장 사항

카드 목록은 제공된 영문 규칙서와 `Chateau Combo Card Roster May 2025`를 기준으로 작성했습니다. 실제 소유한 판본에서 카드 문구가 다를 경우 `app.js`의 해당 카드 데이터를 수정하세요.
